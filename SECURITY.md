# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please report security issues privately through
[GitHub private vulnerability reporting](https://github.com/AhsinMehmood/velvet_motion/security/advisories/new)
on this repository.

Do not open a public issue for security reports. You can expect an initial
response within a few days, and a fix or mitigation plan as soon as practical.
